CUT THE FLOW — mode d'emploi
===========================

Ce dossier contient le studio de montage complet. Rien à installer, rien à
télécharger en plus : l'interface est embarquée dans l'exécutable.

DÉMARRER
--------
Windows   double-cliquez sur  DEMARRER.cmd
Linux     dans un terminal :  bash demarrer.sh
macOS     double-cliquez sur  demarrer.command
          (ou dans le Terminal :  bash demarrer.command)

Le studio s'ouvre dans SA PROPRE FENÊTRE — sans onglets ni barre d'adresse,
comme une application. Il s'appuie sur Chrome, Edge, Brave ou Chromium déjà
installé, en « mode application ». Si aucun de ces navigateurs n'est présent,
le studio s'ouvre dans votre navigateur par défaut : même contenu, avec des
onglets en plus.

Laissez la fenêtre noire (ou le terminal) ouverte pendant le montage :
la fermer arrête le studio.

POURQUOI UNE FENÊTRE DE NAVIGATEUR ?
------------------------------------
Ce n'est pas un oubli : l'interface du studio est une application web, et elle
a besoin d'un moteur de rendu pour s'afficher. L'exécutable fournit le moteur
d'export (Rust + ffmpeg) et sert l'interface depuis votre machine, sur
http://127.0.0.1:7317/ — une adresse locale, invisible depuis Internet.
Rien n'est envoyé nulle part et aucune donnée ne quitte l'ordinateur.

Vous pouvez installer le studio comme application (icône, fenêtre sans
navigateur visible) : dans la fenêtre du studio, ouvrez le menu du navigateur
puis « Installer CUT THE FLOW » (Chrome / Edge).

IMPORTANT (Windows) : gardez cuttheflow.exe ET libunwind.dll dans le même
dossier. Sans le .dll, Windows refuse de démarrer l'exécutable sans expliquer
pourquoi. Si vous déplacez l'exécutable, déplacez les deux.

IMPORTANT (macOS) : au premier lancement, macOS peut afficher « développeur non
identifié ». Le lanceur lève lui-même ce blocage pour ce binaire. Si le
double-clic ne fait rien (archive ZIP : le fichier n'est pas exécutable),
ouvrez le Terminal dans ce dossier et tapez :  bash demarrer.command

FICHIERS
--------
  cuttheflow           le moteur et l'interface (Windows : cuttheflow.exe)
  libunwind.dll        Windows uniquement — dépendance de l'exécutable
  DEMARRER.cmd         lanceur Windows
  demarrer.sh          lanceur Linux
  demarrer.command     lanceur macOS
  LISEZ-MOI.txt        ce fichier
  LICENSE              licence du logiciel

FFMPEG : OPTIONNEL
------------------
Le studio fonctionne de deux façons :

  • SANS ffmpeg — tout se fait dans votre navigateur (WebCodecs). Import,
    montage, aperçu et export MP4 / WebM / MP3 fonctionnent normalement.
    C'est le mode choisi automatiquement quand ffmpeg est absent.

  • AVEC ffmpeg — le moteur natif prend le relais : rendu identique sur toutes
    les machines, meilleur contrôle du débit. Recommandé pour les projets
    longs ou lourds.

Pour l'activer, installez ffmpeg une seule fois :

  Windows   winget install Gyan.FFmpeg
  macOS     brew install ffmpeg
  Linux     sudo apt install ffmpeg        (ou dnf install ffmpeg)

Vous pouvez aussi poser ffmpeg et ffprobe directement dans ce dossier.
Pour vérifier ce qui est détecté :  cuttheflow doctor
Pour forcer un emplacement : variables CTF_FFMPEG et CTF_FFPROBE.

UTILISATION SANS INTERFACE
--------------------------
  cuttheflow doctor
  cuttheflow probe mon-film.mp4
  cuttheflow export projet.json --out montage.mp4 --format mp4 --crf 18

OÙ SONT MES FICHIERS
--------------------
Médias importés, exports et cache restent sur cette machine, dans :

  Windows   %LOCALAPPDATA%\cuttheflow
  Linux     ~/.local/share/cuttheflow
  macOS     ~/Library/Application Support/cuttheflow

Aucune donnée ne quitte l'ordinateur : le serveur n'écoute que sur 127.0.0.1
et refuse les connexions venant d'ailleurs.

EN CAS DE PROBLÈME
------------------
  • Rien ne se passe au double-clic (Windows) : libunwind.dll manque, ou
    l'archive a été ouverte sans être extraite. Extrayez tout le dossier.
  • « ffmpeg est introuvable » : normal sans ffmpeg, le studio bascule en mode
    navigateur. Installez ffmpeg pour utiliser le moteur natif.
  • Le port 7317 est déjà pris :  cuttheflow serve --port 7320
  • Tout autre cas :  cuttheflow doctor  (diagnostic lisible)
